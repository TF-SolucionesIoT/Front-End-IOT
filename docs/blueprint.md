# **App Name**: ElderTrack

## Core Features:

- User Authentication: Secure login and registration for patients and caregivers.
- Dashboard Overview: Display key metrics like vitals, emergency alerts, and reminders.
- Real-time Vitals Monitoring: Continuously monitor vital signs with visual trends.
- Emergency Alert System: One-touch SOS button and automated emergency alerts based on vital signs.
- Medication Reminders: Schedule and track medication intake with reminders.
- Caregiver Collaboration: Allow caregivers to monitor patients' vitals and receive alerts.
- Smart Alerting Tool: AI tool evaluates vitals data to determine the need for escalation or intervention, notifying caregivers and emergency contacts based on predefined thresholds and patterns.

## Style Guidelines:

- Primary color: Deep blue (#0056B3), providing a sense of trust and stability for key actions.
- Background color: Very light gray (#F6F8FA), minimizing visual fatigue.
- Accent color: Sea green (#0AA3A3), analogous to the primary, used to highlight vitals and informative sections.
- Font: 'Inter' (sans-serif) for both headings and body text, optimized for screen readability, ensuring clarity for elderly users. Note: currently only Google Fonts are supported.
- Use clear, high-contrast icons for navigation and important actions.
- Prioritize a clean, spacious layout with a clear information hierarchy to reduce cognitive load.
- Use subtle animations to guide the user and provide feedback on interactions without causing distraction.
